## Archetypes

- **Note 1 (mark 13): §6 grouped closed set** — 2 ordered items, one cloze number, printed
  ordinals (rule 26: position is scaffolding, never an answer), rows separated `<br><br>`
  (R14) so the answer count is visible at a glance. Count stays visible in the stem per
  §6 ("name the parent and its count"); a separate "two" numeric card would be padding
  since producing both rows already proves the count.
- **Note 2 (mark 14): the trap fact tested as its own card**, per the drafting brief. The
  duty ("should <b>always</b> clarify in advance") and the pivot word ("three") stay
  visible as the frame; the recall is the closed pair of horns the clarification decides
  between, both under c1. Deliberate rejections, for the record:
  - clozing only "clarify" (filler-verb blank, rule 22 shape);
  - clozing "three" (decodable by any careful reader — the ambiguous word is obviously
    the final count);
  - a classify card over the two example commands (each command's own wording derives
    its answer, so it drills parsing, not recall);
  - a 15-word whole-duty cloze (rule 5 / rule 15, uncrisp).
  Note the horns share vocabulary with note 1's set — by design, not duplication: note 1
  tests the two-part STRUCTURE; note 2 tests the countdown's AMBIGUITY between those two
  parts and the always-clarify duty. Rule 21 check: the absolute carries no lone unhinted
  blank — the "whether … or …" frame plus the visible anchor "three" close the answer
  space.
