## Flags for hand-off

- **KED fragment (P15):** m15's context opens mid-sentence — "…a patient quickly from a vehicle while providing as much protection to the spine as would a spinal immobilization device such as a Kendrick extrication device (KED)." The start of the sentence (presumably "It is impossible to remove…") is outside the window, so the claim "no emergency move protects the spine as well as a KED" was NOT asserted anywhere. Unmarked and incomplete → no card. If Parker wants it, the p799 sentence start needs reading.
- **Blanket drag (P5):** deliberately has no dedicated pairing card — the name gives the technique away in both directions (rule 20 padding / rule 3 leak). Its one non-derivable detail (any pullable item, e.g. a coat) is tested nowhere but taught in J1's Back Extra. Editor may re-judge.
- **"Long-axis body drag" (J7):** the book says "as previously described, use a long-axis body drag"; the earlier description is unmarked, so the term is used, not defined, on J7 (answer-side only, with a `::type of drag` form hint). If Parker wants a definition card for it, that is unmarked content — his call.
- **`step_recitation` pre-clearance rationale:** J5/J6/J7 are sequence-adjacent but each is a single decision or end-state value with ordinals printed, never clozed — rule 26 shapes, not step lists.
- **J1's "four" and its verification:** the digit 4 never appears in the source text; it is a count of the enumerated methods (m15 context) against the four FIGURE 8-14 labels (m16 context, blessed by VERIFIED BLOCK 4). Recorded as verified_against p799-800.
