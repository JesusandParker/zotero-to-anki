The rewritten vignette (older adult + struck head + normal exam → the bleed can go unnoticed) is coherent, shorter, and stronger, because the drafter's version also **did the reasoning for him** ("Your suspicion stays high because…") and then asked him to complete the punchline.
3. *"The brief requires the phrase for the figure matcher."* **This is factually wrong, and I checked the code rather than assuming.** `match_figures.score()` computes coverage from `cloze_answers(card["Text"])` only — visible non-clozed text is never read. #9's sole answer ("may go unnoticed for some time") shares nothing with FIGURE 7-14's terms, so #9 scores 0.00 and is blocked by the R19 zero-coverage rule **whatever its visible text says**. Removing the phrase costs the matcher nothing.

So the reword was free, and the leak was not. Rewritten.
